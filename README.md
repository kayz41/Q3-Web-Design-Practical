# Question 03 — Makerere University Examination Results

A responsive examination-results page for a fictional Year 2 Bachelor of Science in Information Technology cohort.

## Files
- `index.html` — results table, grade legend and publication details
- `results.css` — external stylesheet

The student names, registration numbers and marks are fictional sample data for the practical. The supplied banner image is referenced from the preserved master coursework repository.

## Run locally
Open `index.html` in a browser.
